Přání paní doktorce Starkové
============================
Jedná se o jednoduchou aplikaci, které sbírá příní k narozeninám pro paní doktorku Starkovou, ze kterých bude sestavena fotokniha.
Tato fotokniha bude předána paní doktorce k jejímu významnému jubileu v červnu 2026.

Doufám, že se podaří posbírat dostatek přání, protože si myslím, že je dobré, aby paní doktorka věděla, že se na ní nezapomnělo.
